# Radius Scout

Radius-based POI discovery tool built with:

- Leaflet
- OpenStreetMap
- Nominatim
- Overpass API

## Features

- Address search
- Radius overlay
- Dynamic POI filters
- Interactive summary filtering
- Dark premium UI
- Mobile responsive

## Deployment

1. Upload to GitHub
2. Enable GitHub Pages
3. Deploy from main branch

## Free APIs Used

- Nominatim (geocoding)
- Overpass API (POI)
- CARTO Dark Matter tiles
